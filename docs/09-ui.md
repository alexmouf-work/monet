# 09 — UI specification

Paint-3D-inspired: **feature tabs across the top, one contextual options panel on
the right**, canvas workspace in the middle, sources on the left. Clean, flat,
large hit targets. Light theme with a dark workspace surround (theme work is
polish, not v1 scope — hard-code the palette below).

- `☰` = app menu (§2). `⚙` = settings dialog. `⤓` = export dialog. **Sync** [08 §7].

- Panels are fixed-width; workspace flexes. Minimum window 1100×640; below that
  the sources sidebar auto-collapses.

## 3. Feature tabs → options panel contents

The active tab decides both the **active tool family** and the right panel.
Switching tabs commits any pending state (open text edit, live preview → prompt
"Apply noise? Apply / Discard" if previewing with changes).

### 3.1 Brushes [02]
Tool grid (icon buttons): **Pixel pen · Marker · Eraser · Bucket · Eyedropper**,
then the active brush's controls (size slider+numeric 1–64, tip ◯/▢ toggle;
bucket: tolerance 0–100 %). Footer note shows the `Alt`-eyedropper hint.

### 3.2 Shapes [03]
Type grid with icons (triangle, rectangle, pentagon, hexagon, circle, ellipse,
arrow, arrowhead, line, spline) · Fill: ✔ + swatch + opacity slider · Outline:
✔ + swatch + opacity + weight 1–64 · Crisp edges ✔ · numeric X/Y/W/H ·
**Rotation 0–360°** slider+numeric · (spline hint: "click to add points — Enter
finishes, Esc cancels").

### 3.3 Text [03 §6]
Font dropdown (Monocraft default, bundled + generic; optional system-font
loader) · size 4–256 · **B I U** toggles · align ⟸ ⟺ ⟹ · colour + opacity ·
Rotation 0–360° · Crisp ✔.

### 3.4 Noise [04 §1] — type dropdown (grouped), rotation, scale, intensity,
Brightness/Hue checkboxes, seed + 🎲, **Apply** / **Reset**, objects-hint line.

### 3.5 Recolour [05 §1] — Replace | Tint segmented control and the mode's
controls; **Recolour** button; objects-hint line.

### 3.6 Canvas [06 §1] — Background: Transparent|Colour + swatch · Resize…
(opens dialog) · Rotate ⟲ ⟳ · Flip ↔ ↕ · readout "32 × 32 px".

**Select** is a persistent tool button pinned left of the feature tabs (with Pan
next to it) — selection & moving are cross-cutting, not a tab.

## 4. Sources sidebar [08]

Header "+ Add ▸" → *Minecraft/mod jar…*, *GitHub repository…*, *Local folder…*.
Each source: an accordion with icon (🫙 jar / ⎇ repo / 📁 folder), label, kebab
menu (Refresh, Reconnect (folder), Sync… (repo), Remove), then the texture tree
[08 §1]. Repo rows show `work ← base` badges and the last push status.

## 8. Cursors & affordances

Brushes: `crosshair` + tip-outline overlay [02 §3.4] — the system cursor stays
**visible** on top of the outline (owner directive 2026-08-09: hiding it left
nothing to track at low zoom, where the outline is only a pixel or two across);
bucket/eyedropper: SVG
cursors with correct hot-spots (`cursor: url(...) x y, crosshair`); select:
default arrow, `move` inside selections/objects, rotate cursor near the rotation
handle, resize cursors matching each handle's angle (recompute for rotated
objects: pick from 8 directions by `handleAngle + rotation`); pan: `grab`/
`grabbing`; text: `text` over text objects.

Toasts (top-right, 4 s, dismissible): save/push results, sync results, errors.
Every icon button has a `title` tooltip incl. its shortcut.

## 9. Workspace palette (hard-coded v1)

Surround `#3d3d40` · panels `#f5f6f8` · panel borders `#d9dce1` · text `#1c1e21`
· accent (selection, active states) `#3fa7d6` · marching ants: 1 px black over
1 px white dashes · handles: white fill, `#3fa7d6` border, 8×8 px.

## 10. Acceptance

- The full §1 layout at 1280×800 with all regions live; sidebar collapse works.
- Every §7 shortcut fires its action, and none fire while typing in fields.
- Tab switching prompts on unsaved noise/recolour previews and commits open text
  edits.
- All dialogs open, validate, confirm and cancel per §6; keyboard-only operation
  (Tab/Enter/Esc) possible throughout.
- Colour panel: palette order exact, hex round-trip, custom swatches persist
  across reloads, recents update.
- E2E screenshot of the default view matches a locked golden at 1280×800.
